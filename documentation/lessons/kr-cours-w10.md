# Coréen — Semaine 10 · Unité 6, L'heure (시간)

Cours GEE3003 « Active Korean 1 », 제6과 **시간** (week_10.pdf) : **dire
l'heure** (시 avec les nombres **natifs**, 분 avec les nombres
**sino-coréens**), **오전 / 오후**, **반**, les **jours de la semaine**
(요일), la particule de temps **에**, **에도 / 에는**, et le contraste
**-지만**.

> **En bref.** **Heures = nombres natifs** (한 시, 두 시, 세 시, 네 시…
> 열두 시) ; **minutes = sino-coréens** (십 분, 삼십오 분). 2 h 30 = 두 시
> 삼십 분 = **두 시 반**. **오전** = a.m., **오후** = p.m., placés **avant**
> l'heure. Jours : **월·화·수·목·금·토·일 + 요일**. **N에** = « à / le »
> (temps) : 일곱 시**에** 일어나요, 월요일**에** ; **pas de 에** après **오늘,
> 내일, 어제, 지금**. **V/A-지만** = « mais » : 학교에 가**지만** 애니 씨는 안
> 가요.

## Vocabulaire (어휘)

### Le temps

- heure (… heures) = 시 = si
- minute = 분 = bun
- week-end = 주말 = ju-mal
- matin (a.m.) = 오전 = o-jeon
- après-midi (p.m.) = 오후 = o-hu
- demie (… et demie) = 반 = ban

### Les jours de la semaine (요일)

| lundi | mardi | mercredi | jeudi | vendredi | samedi | dimanche |
|---|---|---|---|---|---|---|
| 월요일 | 화요일 | 수요일 | 목요일 | 금요일 | 토요일 | 일요일 |

**일 - 월 - 화 - 수 - 목 - 금 - 토 + 요일** (la semaine coréenne commence
souvent par le dimanche 일요일).

### Interrogatifs et autres

- quel (genre de) = 무슨 = mu-seun
- quand = 언제 = eon-je
- se lever = 일어나다 = i-reo-na-da
- environ (… vers) = 쯤 = jjeum
- dormir = 자다 = ja-da
- je / moi (familier) = 나 = na
- grand magasin = 백화점 = baek-hwa-jeom
- être cher = 비싸다 = bi-ssa-da
- travailler = 일하다 = il-ha-da
- prendre une douche = 샤워하다 = sya-wo-ha-da

> **Pièges :**
> - devant 시, les natifs prennent leur **forme courte** : **한** (pas
>   하나), **두** (pas 둘), **세** (pas 셋), **네** (pas 넷), **열한**, **열두**
>   — comme devant un compteur (S5) ;
> - les minutes ne sont **jamais** natives : « 삼십 분 », jamais « 서른 분 » ;
> - **오전 / 오후** se placent **avant** l'heure ;
> - **반** remplace **삼십 분**.

## Grammaire 2 : jours de la semaine

- A : 오늘 **무슨 요일**이에요? — B : **화요일**이에요.
- Pour demander le jour, on ajoute **요일** après **무슨** : 무슨 요일이에요?

## Grammaire 3 : N에 (« à », « le » — moment)

La particule **에** suit un **nom de temps** (heure, jour, moment) :

| Avec 에 | Sans 에 |
|---|---|
| 일곱 시**에** 일어나요. (à 7 h) | **오늘** 뭐 해요? |
| 월요일**에** 태권도를 배워요. | **내일** 학교에 가요? |
| 주말**에** 영화를 봐요. | **지금** 책을 읽어요. |
| 오후**에**, 아침**에** | **어제** … |

> **Règle :** **에** ne s'emploie **pas** après **어제, 오늘, 내일, 지금**.
> Corrigé de l'exercice : 1) 주말(**에**) 영화를 봐요. 2) 오늘(**X**) 뭐 해요?
> 3) 지금(**X**) 책을 읽어요. 4) 무슨 요일(**에**) 태권도를 배워요?

- A : 몇 시**에** 일어나요? — B : 일곱 시**에** 일어나요.
- A : 몇 시**에** 밥을 먹어요? — B : 여덟 시**쯤에** 먹어요. (**쯤** =
  environ)

## Grammaire 4 : 에도 / 에는

| Forme | Sens | Exemple |
|---|---|---|
| **N에도** | « **aussi** à ce moment-là » : la même chose à un autre moment | 화요일**에도** 태권도를 배워요? (le mardi **aussi** ?) |
| **N에는** | met en **contraste** / en **relief** ce moment | 아니요, 화요일**에는** 태권도를 **안** 배워요. (le mardi, **non**) |

- A : 무슨 요일에 태권도를 배워요? — B : 월요일에 태권도를 배워요.
- A : 화요일에도 태권도를 배워요? — B : 아니요, 화요일에는 태권도를 안
  배워요.

## Grammaire 5 : V/A-지만 (« mais »)

Pour **opposer** deux phrases, on ajoute **-지만** au **radical** (on enlève
다) du verbe ou de l'adjectif de la **première** phrase :

| Verbe | Radical + 지만 |
|---|---|
| 가다 | 가**지만** |
| 먹다 | 먹**지만** |
| 공부하다 | 공부하**지만** |
| 싸다 | 싸**지만** |

- A : 내일 학교에 가요? — B : 나는 학교에 **가지만** 애니 씨는 안 가요.

**Corrigé de « Link two sentences using -지만 »** :

1. 나는 밥을 **먹지만** 쿠미르 씨는 빵을 먹어요.
2. 나는 한국어를 **공부하지만** 미사코 씨는 영어를 공부해요.
3. 애니 씨는 백화점에 **가지만** 크리스 씨는 시장에 가요.
4. 바나나는 **싸지만** 포도는 비싸요.

## Conversation (대화 연습)

- A : ( ) 씨, 오늘 뭐 해요? — B : 학교에 가요.
- A : 몇 시에 학교에 가요? — B : 아홉 시에 학교에 가요.
- A : 주말에 뭐 해요? — B : 토요일에는 운동해요.
- A : 일요일에도 운동해요? — B : 아니요, 토요일에는 운동하**지만**
  일요일에는 청소해요.
