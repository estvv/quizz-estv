# Coréen — Semaine 9 · Unité 5, Vie quotidienne (일상생활) — vocabulaire

Cours GEE3003, **Unit 5 Daily Life 일상생활** (vocabulary.pdf). Cette
semaine, le dossier ne contient que la **liste de vocabulaire** : lieux,
temps, verbes, noms, adjectifs, interrogatifs et petits mots. Les phrases
modèles de la fiche sont reprises à la fin.

> **En bref.** Des **lieux** (공원, 식당, 학교, 병원, 산, 시장, 집), des
> mots de **temps** (지금, 오늘, 내일, 요즘), des **verbes d'activité** en
> **-다** (먹다, 만나다, 좋아하다, 사다, 배우다, 입다, 마시다, et les verbes
> en **하다** : 운동하다, 공부하다, 청소하다, 빨래하다), des **adjectifs**
> (맛있다, 따뜻하다, 싸다, 좋다, 복잡하다, 재미있다), et **어디** (où),
> **뭘** (quoi), **안** (ne … pas), **그리고** (et), **아주** (très), **우리**
> (nous).

## Lieux (장소)

- lieu / endroit = 장소 = jang-so
- parc = 공원 = gong-won
- restaurant = 식당 = sik-dang
- école = 학교 = hak-gyo
- hôpital = 병원 = byeong-won
- montagne = 산 = san
- marché = 시장 = si-jang
- maison = 집 = jip

## Temps (시간)

- temps / heure = 시간 = si-gan
- maintenant = 지금 = ji-geum
- aujourd'hui = 오늘 = o-neul
- demain = 내일 = nae-il
- ces temps-ci = 요즘 = yo-jeum

## Verbes (동사)

- faire = 하다 = ha-da
- manger = 먹다 = meok-da
- rencontrer = 만나다 = man-na-da
- aimer = 좋아하다 = jo-a-ha-da
- acheter = 사다 = sa-da
- apprendre = 배우다 = bae-u-da
- porter (un vêtement) = 입다 = ip-da
- boire = 마시다 = ma-si-da
- faire du sport = 운동하다 = un-dong-ha-da
- étudier = 공부하다 = gong-bu-ha-da
- regarder / voir = 보다 = bo-da
- faire le ménage = 청소하다 = cheong-so-ha-da
- faire la lessive = 빨래하다 = ppal-lae-ha-da
- enseigner = 가르치다 = ga-reu-chi-da

> **Astuce :** beaucoup de verbes = **nom + 하다** : 운동 (sport) + 하다 =
> 운동하다 ; 공부 (études) + 하다 = 공부하다 ; 청소 + 하다 ; 빨래 + 하다.

## Adjectifs (형용사)

En coréen, un adjectif se conjugue **comme un verbe** (forme du
dictionnaire en **-다**) : 맛있다 = « **être** délicieux ».

- être délicieux = 맛있다 = ma-sit-da
- être doux / tiède (temps) = 따뜻하다 = tta-tteu-ta-da
- être bon marché = 싸다 = ssa-da
- être bien / bon = 좋다 = jo-ta
- être bondé / embouteillé = 복잡하다 = bok-ja-pa-da
- être intéressant / amusant = 재미있다 = jae-mi-it-da

> **Contraires utiles :** 싸다 (bon marché) ↔ **비싸다** (cher, S7 et S10) ;
> 재미있다 ↔ 재미없다 ; 맛있다 ↔ 맛없다 (있다 / 없다 = avoir / ne pas avoir).

## Interrogatifs (의문사) et autres mots

- où = 어디 = eo-di
- quoi (complément) = 뭘 = mwol (= 무엇을)
- ne … pas (devant le verbe) = 안 = an
- et (entre deux phrases) = 그리고 = geu-ri-go
- très = 아주 = a-ju
- nous / notre = 우리 = u-ri

## Les phrases modèles de la fiche

| Coréen | Sens |
|---|---|
| 날씨가 좋다. | Il fait beau. (la météo est bonne) |
| 길이 복잡하다. | La route est encombrée. |
| 날씨가 따뜻하다. | Il fait doux. |

Ces phrases suivent le modèle **N이/가 + adjectif** (S7) : **날씨가**
(씨 = voyelle → 가), **길이** (길 finit par ㄹ → 이).

> **안 + verbe** (négation) : 안 + 먹다 → « ne pas manger » ; il se place
> **juste devant** le verbe ou l'adjectif. On le revoit à l'oral en S10 :
> 화요일에는 태권도를 **안** 배워요.
