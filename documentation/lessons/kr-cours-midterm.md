# Coréen — Mid Term (Semaines 1–7) · Plan de révision

Le **midterm exam** (semaine 8 du syllabus : **grammar, reading, writing**)
couvre tout le cours depuis la semaine 1. Cette catégorie mélange des
questions de **toutes les leçons du Cours** (Semaines 1 à 5 et l'entraînement
-(으)세요) dans le style d'un examen : lire le hangeul, choisir la bonne
particule ou terminaison, compter, comprendre et écrire de courtes phrases.

**Méthode conseillée :**

1. Faire ce quiz une première fois à froid : **Toutes** puis **Aléatoire**.
2. Pour chaque semaine où tu rates des questions, relire la **leçon** de la
   semaine puis refaire son quiz.
3. Réviser les mots avec les decks du **Vocabulaire** (pays, métiers,
   boissons, aliments, nombres, compteurs).
4. La veille : réécrire de mémoire une **présentation** (nom, nationalité,
   métier) et une **commande au restaurant**.

## La checklist par semaine

| Semaine | Ce qu'il faut savoir sans hésiter |
|---|---|
| **S1** · Hangeul de base | voyelles = **•** (ciel), **ㅡ** (terre), **ㅣ** (humain) ; 10 voyelles ㅏ ㅑ ㅓ ㅕ ㅗ ㅛ ㅜ ㅠ ㅡ ㅣ ; **ㅓ** (o ouvert) ≠ **ㅗ** (o fermé), **ㅜ = [ou]** ; voyelle seule → **ㅇ muet** devant (아, 오) ; verticales **à droite**, horizontales **dessous** ; consonnes = forme de la bouche, **un trait = plus fort** ; ㅇ muet au début, **[ng]** à la fin |
| **S2** · Consonnes fortes, 받침 | **aspirées** ㅊ ㅋ ㅌ ㅍ (souffle) ; **tendues** ㄲ ㄸ ㅃ ㅆ ㅉ (sans air) ; ㅅ n'a **pas** d'aspirée ; voyelles composées (ㅗ + ㅏ = **ㅘ**, ㅜ + ㅓ = **ㅝ**, ㅡ + ㅣ = **ㅢ**) ; **받침 = 7 sons** [k] [n] [t] [l] [m] [p] [ng] (꽃, 옷, 낮 → [t]) |
| **S3** · Salutations | **안녕히 가세요** (à qui part) / **안녕히 계세요** (à qui reste) ; **이에요** (consonne finale) / **예요** (voyelle) ; **은** (consonne) / **는** (voyelle) ; nationalité = **pays + 사람** ; **씨** après le nom ; pays et métiers |
| **S4** · -(으)세요 | enlever 다 ; voyelle → **세요**, consonne → **으세요** ; **마시다 / 먹다 → 드세요** ; 주다 → 주세요 ; **사람이에요** toujours |
| **S5** · Au restaurant | **N 주세요** ; nombres natifs **하나 … 열**, devant un compteur **한 / 두 / 세 / 네** ; **개** (objets), **병** (bouteilles), **잔** (verres), **명** (personnes), **분** (personnes, poli) ; ordre **nom + nombre + compteur** ; **하고** (et), **좀** (adoucit), **더** (encore) ; 어서 오세요, 뭐 드릴까요?, 여기요, 잠깐만 기다리세요, 여기 있어요 |

## Les modèles à savoir écrire

| Situation | Modèle |
|---|---|
| Se présenter | 안녕하세요? 저는 ___예요/이에요. 저는 ___ 사람이에요. 저는 ___예요/이에요. 만나서 반가워요. |
| Présenter quelqu'un | 여기는 ___ 씨예요. |
| Demander le nom | 이름이 뭐예요? |
| Commander | 불고기 하나하고 콜라 두 병 주세요. |
| Redemander | 여기요. 물 좀 더 주세요. |
| Nombre de personnes | 몇 분이에요? — 세 명이에요. |
